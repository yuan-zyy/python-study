#### 3.13.3 比较运算符

##### <span style="color:red">3.13.3. 1逻辑运算符规则（重点）</span>

###### 1. 两大比较核心

- <span style="color:red">**`== `、`!=`**</span>
  - 判断：**内容或值是否相等**
  - 任意类型都可以比较，**不报错**
  - 类型不同 --> 绝大多数返回 `False`
- <span style="color:red">**`is`、`is not`**</span>
  - 判断：**是否是同一个对象（内存地址相同）**
  - 比较的是 `id()`
  - 内容相等 `== True`，对象不一定相同 `is False`

###### 2. 不同类型通用规则（Python3）

- **相同 或 兼容类型**
  - `==` 、 `!=`：按值比较
  - `< <= > >=`：正常比较大小 或 顺序
- <span style="color:red">**不同类型（跨大类）**</span>
  - <span style="color:red">**`==`、`!=`：可比较，结果是 `False`**</span>
  - `< <= > >=`：**直接抛 TypeError**
- **唯一兼容类型组**
  - `int ↔ float ↔ bool`
  - `bool` 是 `int` 子类：`True == 1`、`False == 0`

###### 3. 各类型比较规则

- **数字（int/float/bool）**

  互相兼容，**按数值大小比较**

  ```python
  1 == 1.0        # True
  True == 1       # True
  False == 0      # True
  1.5 > 1         # True
  ```

- **字符串 str**

  按 **Unicode 编码逐个字符比较**

  ```python
  "a" < "b"       # True
  "10" < "2"      # True（按字符逐位比）
  ```

- **列表 list / 元组 tuple**

  - 按**元素逐个比较**
  - 列表与元组类型不同：`[1,2] == (1,2) → False`

  ```python
  l1 = [1, 2, 3]
  l2 = [2, 1, 3]
  
  print(l1 == l2) # False
  print(l1 < l2) # True
  ```

- **字典 dict**

  - 只支持 `==`、`!=`（键值都相同才相等）
  - <span style="color:red">**不支持 `< <= > >=`**，比较直接报错</span>

###### 4. <span style="color:red">集合 set 比较（重点）</span>

- `==`：**内容相等**

  集合**无序、不重复**，元素相等即相等

  ```python
  {1,2} == {2,1}    # True
  ```

- `is` **对象相同**

  内容一样也可能是不同的对象

  ```python
  a = {1,2}
  b = {1,2}
  a is b            # False
  ```

- `< <= > >=`：**子集、超集（集合独有）**

  - `a < b`：a 是 b 的**真子集**
  - `a <= b`：a 是 b 的**子集**（可相等）
  - `a > b`：a 是 b 的**真超集**
  - `a >= b`：a 是 b 的**超集**

  ```python
  {1} < {1,2,3}     # True
  {1,2} <= {1,2}    # True
  {1,2} < {1,2}     # False
  set() < {1}       # True（空集是任何非空集合真子集）
  ```

- **集合与其他类型比较**

  - `set == list/tuple/int/str` → `False`
  - `set < list` 等大小比较 → **TypeError**

#### 3.13.4 逻辑运算符

Python 有**3 个核心逻辑运算符**，专门用于**判断多个条件的真假**，返回结果只有 `True` 或 `False`（布尔的逻辑计算）

<span style="color:red">**分别是：`and`（与）、`or`（或）、`not`（非）**</span>

##### 3.13.4.1 `and`（与）

**规则**：**所有条件都为 True，结果才是 True**；只要有一个为 False，结果就是 False。

> 口诀：**全真才真，一假则假**

```python
# 示例
print(True and True)   # True
print(True and False)  # False
print(5 > 3 and 2 < 4) # True（两个条件都满足）
print(5 > 3 and 2 > 4) # False（一个条件不满足）
```

##### 3.13.4.2 `or`（或）

**规则**：**只要有一个条件为 True，结果就是 True**；全部为 False，结果才是 False。

> 口诀：**一真则真，全假才假**

```python
# 示例
print(True or False)  # True
print(False or False) # False
print(1 > 5 or 3 < 6) # True（一个条件满足）
print(1 > 5 or 3 > 6) # False（都不满足）
```

##### 3.13.4.3 `not`（非）

**规则**：**取反**，True 变 False，False 变 True。

> 口诀：**真变假，假变真**

```python
# 示例
print(not True)  # False
print(not False) # True
print(not 5 > 3) # False（5>3是True，取反后False）
```

##### 3.13.4.4 优先级（重要）

运算顺序：**`not` > `and` > `or`**

先算 not，再算 and，最后算 or

```python
# 示例
print(True or False and not False)
# 步骤：先算 not False → True
# 再算 False and True → False
# 最后算 True or False → True
```

##### <span style="color:red">3.13.4.4 非布尔的逻辑计算（重要）</span>

在 Python 中，逻辑运算符（`and`, `or`, `not`）的返回值并不总是简单的 `True` 或 `False`

- **`not` 规则：始终返回布尔值**

  - `not 0`  --> True
  - not `Hello` --> False

- **`and` 规则**

  - 从左往右找**第一个假值**，找到就返回它
  - 全为真，返回**最后一个真值**

  ```python
  print(0 and 1)      # 0（第一个假）
  print("" and "abc") # ""（第一个假）
  print(1 and 2 and 3)# 3（全真，返回最后一个）
  ```

- **`or` 规则**

  - 从左往右找 **第一个真值**，找到就返回它
  - 全为假，返回 **最后一个假值**

  ```python
  print(0 or 1)       # 1
  print("" or None)   # None
  print(1 or 2 or 3)  # 1
  ```

#### 3.13.6 成员运算符

Python 的**成员运算符**用来**判断一个值是否在指定的序列（字符串、列表、元组、集合、字典）中**，返回结果是布尔值：`True`（存在）或 `False`（不存在）

| 运算符   | 作用                                  | 示例                        |
| -------- | ------------------------------------- | --------------------------- |
| `in`     | 判断值**在**序列中，是则返回 `True`   | `3 in [1,2,3]` → `True`     |
| `not in` | 判断值**不在**序列中，是则返回 `True` | `4 not in [1,2,3]` → `True` |

1. **字符串**

   判断**子字符串 / 字符**是否存在

   ```python
   s = "Hello Python"
   print("H" in s)       # True（字符H存在）
   print("Py" in s)      # True（子串Py存在）
   print("hello" in s)   # False（区分大小写）
   print("123" not in s) # True
   ```

2. **列表 / 元组**

   判断**元素**是否存在

   ```python
   # 列表
   lst = [10, 20, 30, "Python"]
   print(20 in lst)      # True
   print(50 not in lst)  # True
   
   # 元组（用法和列表完全一致）
   tpl = (5, 6, 7)
   print(5 in tpl)       # True
   ```

3. **集合**

   判断**元素**是否存在（效率比列表高）

   ```python
   s = {1, 2, 3}
   print(2 in s)   # True
   ```

4. **特殊：字典的成员判断**

   **字典中 `in` 只判断「键（key）」，不判断值（value）！**

   ```python
   dic = {"name": "张三", "age": 20}
   
   # 判断键是否存在
   print("name" in dic)  # True
   print("age" not in dic) # False
   
   # 判断值需要用 values()
   print(20 in dic.values())  # True
   # 判断键值对需要用 items()
   print(("name", "张三") in dic.items()) # True
   ```

5. 常用场景

   1. 条件判断（最常用）

      ```python
      username = input("请输入用户名：")
      black_list = ["admin", "root"]
      
      if username in black_list:
          print("该用户名不可用")
      else:
          print("用户名可用")
      ```

   2. 循环遍历（结合 `for`）

      `for` 循环本质就是成员运算符的延伸：

      ```python
      for i in [1,2,3]:
          print(i)
      ```

### 3.15 表达式

由数字、符号、括号、变量等的组合。有算数表达式、逻辑表达式、赋值表达式、lambad表达式等等

<span style="color:red; font-size: 30px; font-weight: 700">Python中，赋值即定义</span><span style="font-size: 20px; font-weight: 700">Python 是动态语言，只有赋值才会创建一个变量，并决定了变量的类型和值</span>

<span style="color:red; font-size: 25px; font-weight: 700">如果一个变量已经定义，赋值相当于重新重新定义</span>



Gemini的答案：

**在 Python 中，赋值并不等同于“重新定义”变量，而是将变量名“重新绑定”到了一个新的对象上**

1. **变量是“标签”，而不是“盒子”**

   在很多像 C++ 或 Java 的语言中，变量像是一个有固定大小的**盒子**，赋值是把东西放进盒子里。但在 Python 中，变量更像是**标签（Label）**

   - **第一次定义：** 你创建了一个标签 `x`，并把它贴在了一个名为 `10` 的整数对象上
   - **重新赋值：** 你撕下了标签 `x`，把它贴在了一个名为 `"Hello"` 的字符串对象上

2. **内存层面的变化**

   当你执行以下代码时：

   ```python
   a = [1, 2, 3]  # 定义变量 a
   a = [4, 5, 6]  # 重新赋值
   ```

   - **第一步：** Python 在内存中创建列表 `[1, 2, 3]`，让 `a` 指向它的地址
   - **第二步：** Python 在内存中创建列表 `[4, 5, 6]`，让 `a` 改为指向这个新地址
   - **结果：** 原来的 `[1, 2, 3]` 如果没有其他标签贴着它，就会被 Python 的**垃圾回收机制（Garbage Collection）**清理掉

3. **赋值 vs 修改（可变类型）**

   这一点非常关键。如果变量指向的是一个**可变对象**（如列表、字典），“赋值”和“修改内容”是有本质区别的

   | **操作**     | **代码示例**    | **结果**                                           |
   | ------------ | --------------- | -------------------------------------------------- |
   | **重新赋值** | `a = [4, 5, 6]` | **重新绑定**：变量指向了全新的内存地址。           |
   | **原地修改** | `a.append(4)`   | **修改对象**：变量指向的地址没变，但对象内容变了。 |

**总结一下**

在 Python 里，变量名只是一个引用。重新赋值只是**改变了引用的指向**，而不是在原来的坑位里把旧数据挖出来换成新的。这也就是为什么 Python 被称为“动态类型”语言——你不需要预先声明变量类型，因为类型信息是跟着**对象**走，而不是跟着**变量名**走的

tuple([1,2]) # 转元组
dict()       # 转字典

###### 3.16.1. 1 <span style="color:red; font-size: 25px;">**`int()`**</span>

作用：**把其他类型转成整数（int）**，自带**向下取整、进制转换**功能。

**int () = 转整数 + 截断小数 + 进制转换**

- **最基本用法**

  ```python
  int(3.9)    # 3  （直接截断小数，不是四舍五入）
  int(-2.1)   # -2
  int('123')  # 123（字符串转数字）
  ```

- **常用场景**

  - 去掉小数：`int(99.99)` → 99

  - 输入转数字：

    ```python
    age = int(input("年龄："))
    ```

-  <span style="color:red; font-weight: 700">超强功能：进制转换</span>

  <span style="color: red; font-weight: 700">`int(字符串, 进制)` → 转成十进制整数</span>

  ```python
  int('1010', 2)   # 二进制 1010 → 10
  int('12', 8)     # 八进制 12 → 10
  int('a', base=16)     # 十六进制 a → 10
  ```

- **注意事项**

  - 不能转带非数字的字符串：

    `int('12a')` 会报错

  - 浮点数字符串要先转 float：

    `int(float('3.14'))` → 3

- **内存视角下的 `int`**

  - **对象头（Object Header）：** 每一个 Python 整数对象在内存中都包含：

    - 引用计数（Reference Count）
    - 类型指针（指向 `int` 类）
    - 对象大小

  - 无限精度（Arbitrary Precision）

    C 语言的 `int` 通常限制在 32 位或 64 位，超过就会溢出。而 Python 的 `int` 是**变长对象**。只要你的内存足够大，Python 可以处理成千上万位的数字（例如计算 $2^{1000}$）

  - 整数驻留（Small Integer Caching）

    为了优化性能，Python 会在启动时预先创建 **-5 到 256** 之间的所有整数对象。当你写 `a = 10` 和 `b = 10` 时，它们在内存中其实指向**同一个对象**

- **常见的小坑**

  - **截断 vs 落地：** `int(-3.9)` 的结果是 `-3`，它是向 `0` 的方向取整。如果你需要向下取整（变小），应该用 `math.floor()`
  - **空值报错：** `int("")` 或 `int(None)` 都会报错。在处理外部数据（如 Excel 或 网页输入）时，记得先做判空处理



###### 3.16.1. 2 <span style="color:red; font-size: 25px;">**`str()`**</span>

作用：**把任意数据转成字符串（string）**，是 Python 最常用的内建函数之一

str () = 转成字符串，方便打印、拼接、保存

- **基本用法**

  把数字、列表、布尔值等转成字符串

  ```python
  str(123)      # "123"
  str(3.14)     # "3.14"
  str(True)     # "True"
  str([1,2,3])  # "[1, 2, 3]"
  str({"name": "Tom"})  # "{'name': 'Tom'}"
  ```

- **最常用场景：拼接打印**

  数字不能直接和字符串相加，要用 `str()` 转

  ```python
  age = 18
  print("I am " + str(age) + " years old")
  ```

-  和 `input` 搭配

  `input` 得到的本来就是字符串，**不用再 str ()**

  ```python
  s = input("输入: ")
  print(type(s))  # 已经是 str
  ```

- **`str()` vs `repr()`：两个“面具”**

  这是初学者最容易混淆的地方。Python 中有两种方式将对象转为字符串

  | **函数**     | **目标读者** | **核心目的**                                               | **示例 str(datetime.now())**                 |
  | ------------ | ------------ | ---------------------------------------------------------- | -------------------------------------------- |
  | **`str()`**  | 用户 (User)  | **可读性**。返回一个好看、直观的描述。                     | `"2026-03-28 15:43:52"`                      |
  | **`repr()`** | 开发者 (Dev) | **准确性**。返回一个能表示对象结构的字符串，通常用于调试。 | `datetime.datetime(2026, 3, 28, 15, 43, 52)` |

- <span style="color:red; font-size: 20px; font-weight: 700">编码转换：`str` 与 `bytes`</span>

  在内存模型中，我们需要区分“文本”和“二进制”

  - **`str`**：文本字符串（抽象的字符）
  - **`bytes`**：原始的 8 位字节序列（如 `b'\xff\x00'`）
  - **转换方法**
    - `str` --> `bytes`: 使用 `.encode('utf-8')`
    - `bytes` --> `str`: 使用 `.decode('utf-8')`

- <span style="color:red; font-size: 20px; font-weight: 700">性能小贴士</span>

  由于 `str` 是不可变的，如果你在循环中使用 `+` 来拼接大量字符串

  ```python
  # 低效做法：每次 + 都会在内存中创建新对象
  s = ""
  for char in ["a", "b", "c"]:
      s += char
  ```

  <span style="color:red; font-weight: 700">**更高效的做法：** 使用 `''.join(list)`。它会先计算总长度，一次性在内存中开辟空间，性能提升巨大</span>



###### 3.16.1. 3 <span style="color:red; font-size: 25px;">**`type()`**</span>

作用：**查看一个变量 / 数据的「类型」是什么**

- **基本用法**

  ```python
  type(变量或值)
  ```

- **常见例子**

  ```python
  type(123)      # int（整数）
  type(3.14)     # float（浮点数）
  type('hello')  # str（字符串）
  type(True)     # bool（布尔）
  type([1,2,3])  # list（列表）
  type((1,2))    # tuple（元组）
  type({'a':1})  # dict（字典）
  ```

- **深入内存视角**

  - 当你调用 `type(a)` 时，Python 会顺着标签 `a` 找到内存中的**对象**
  - 每个对象头（Object Header）中都包含一个指针，指向它的**类型对象**
  - `type()` 实际上就是读取并返回了这个指针所指的内容

- **动态创建类（进阶用法）**

  这可能会让你大吃一惊：`type` 本身也是一个类，而且它可以用来**在运行时创建新的类**。当你传入三个参数时，它的功能就变了

  **`type(name, bases, dict)`**

  - **name**: 类名（字符串）

  - **bases**: 父类的元组（用于继承）

  - **dict**: 包含类成员（属性和方法）的字典

    ```python
    # 传统的定义方式
    class Dog:
        def bark(self):
            print("Woof!")
    
    # 使用 type() 动态创建（效果等同）
    DynamicDog = type('DynamicDog', (), {'bark': lambda self: print("Woof!")})
    
    d = DynamicDog()
    d.bark()  # 输出: Woof!
    ```

- **Python 的“套娃”逻辑：元类 (Metaclass)**

  这是 Python 内存模型中最有趣的部分

  - 所有的对象（如 `10`, `[1, 2]`）都是由**类**（如 `int`, `list`）创建的
  - 那么，“类”本身是谁创建的呢？答案是 **`type`**
  - **`type` 是所有类的类**，我们称之为**元类（Metaclass）**

  ----

  ### `isinstance()` vs `type()`

  在实际编程中，如果你想判断一个变量是不是某种类型，通常推荐使用 `isinstance()`：

  | **函数**                   | **特点**                                                     |
  | -------------------------- | ------------------------------------------------------------ |
  | **`type(obj) == int`**     | **严格匹配**。如果 `obj` 是 `int` 的子类，结果为 `False`。   |
  | **`isinstance(obj, int)`** | **考虑继承**。如果 `obj` 是 `int` 或其子类的实例，结果为 `True`。（更符合面向对象的设计） |



###### 3.16.1.4 `isinstance()`

在 Python 的对象模型中，`isinstance()` 是判断对象类型的**首选工具**。它比 `type() == ...` 更强大，因为它理解 **面向对象编程（OOP）** 中的核心概念：**继承**

- **基础语法**

  `isinstance(object, classinfo)`

  - **`object`**: 待检查的对象。
  - **`classinfo`**: 可以是一个**类名**，也可以是由多个类名组成的**元组**。

  ```python
  isinstance(42, int)          # True
  isinstance("Hello", str)      # True
  isinstance(3.14, (int, float)) # True (只要满足元组中的任意一个类型即返回 True)
  ```

- **内存视角下的 `isinstance()`**

  当你调用 `isinstance(obj, ClassA)` 时，Python 在底层做了什么？

  1. 它首先检查 `obj` 对象的头信息，找到它的 `__class__` 指针。
  2. 如果当前类不是 `ClassA`，它会顺着**继承链（MRO - Method Resolution Order）**向上查找。
  3. 只要在继承链中找到了 `ClassA`，就返回 `True`；如果直到根类 `object` 还没找到，则返回 `False`。

- **常见小技巧：判断布尔值**

  有趣的是，在 Python 内存模型中，`bool` 是 `int` 的子类。

  - `isinstance(True, int)` 结果是 **`True`**。
  - 如果你想严格区分布尔值和整数，这时反而需要用到 `type(x) is bool`

###### 3.16.1.5  `input()`

**`input()`** 是程序与用户沟通的桥梁。它在内存和执行流中的行为非常有意思，我们可以从以下几个维度来深度拆解

- 基础行为：程序的中断与等待

  当你调用 `input("提示文字")` 时，Python 解释器会执行以下步骤：

  1. **暂停执行：** 程序运行到这一行会完全停下来，进入**阻塞（Blocking）**状态。
  2. **显示提示：** 将括号内的字符串打印到控制台（标准输出 `stdout`）。
  3. **等待输入：** 等待用户在键盘上输入内容并按下 **Enter（回车键）**。
  4. **捕获数据：** 获取用户输入的所有内容（不包括末尾的回车符）

- **核心特性：永远返回字符串（str）**

  这是初学者最容易掉进去的“坑”。**无论用户输入的是数字、布尔值还是列表，`input()` 捕获后的结果永远是一个 `str` 类型**

  ```python
  age = input("请输入你的年龄: ")
  print(type(age))  # 即使输入 25，输出依然是 <class 'str'>
  ```

  **内存视角的转换：**

  **输入阶段：** 用户输入的 `25` 在操作系统缓冲区是原始字节。

  **捕获阶段：** `input()` 函数将这些字节包装成一个 Python 的 **`str` 对象**存入堆内存。

  **后续处理：** 如果你需要进行数学计算，必须配合我们之前聊过的 `int()` 或 `float()` 进行显式转换： `age_num = int(input("年龄: "))`



###### 3.16.1.6 `print()`

- **基础逻辑：对象的“字符串化”**

  当你执行 `print(obj)` 时，Python 内部实际上经历了两步：

  1. **调用 `str(obj)`：** 询问对象“你长什么样？”，触发对象的 `__str__` 魔术方法。
  2. **发送到 `stdout`：** 将得到的字符串传给操作系统的标准输出

- **四大核心参数（控制输出细节**

  大多数人只用 `print("Hello")`，但掌握这四个参数能让你的输出更有表现力

  | **参数**    | **默认值**    | **作用**                 | **场景示例**                                            |
  | ----------- | ------------- | ------------------------ | ------------------------------------------------------- |
  | **`sep`**   | `' '` (空格)  | 多个参数之间的**分隔符** | `print(1, 2, 3, sep="-")` $\rightarrow$ `1-2-3`         |
  | **`end`**   | `'\n'` (换行) | 输出结束后的**末尾符号** | `print("Hi", end="")` 可以实现不换行连续打印            |
  | **`file`**  | `sys.stdout`  | 输出的**目的地**         | 可以直接把 `print` 的内容写入文件：`print(..., file=f)` |
  | **`flush`** | `False`       | 是否**立即刷新**缓冲区   | 制作进度条或实时日志时非常有用                          |

- **进阶技巧：动态更新（进度条原理**

  利用 `end` 参数和转义字符 `\r`（回车不换行），你可以让控制台的同一行内容发生变化

  ```python
  import time
  
  for i in range(11):
      # \r 让光标回到行首，end="" 阻止换行
      print(f"\r进度: {i*10}%", end="", flush=True)
      time.sleep(0.5)
  ```

- **格式化输出的演变**

  在 `print()` 内部组织复杂的字符串，Python 经历了三个阶段：

  - **旧时代 (`%`)：** `print("Name: %s" % name)` (类似 C 语言，现在不推荐)
  - **过渡期 (`.format`)：** `print("Name: {}".format(name))`
  - **现代派 (f-string)：** `print(f"Name: {name}")`
    - **优点：** 性能最强，可读性最好，支持在 `{}` 里直接写运算逻辑
