# Python str\.format \(\) 完整详解

## 一、基础语法

```python
"模板字符串{}".format(参数1, 参数2, ...)
```

核心规则：

1. `{}` 是占位符，用来填充 `format()` 传入的参数；

2. 字符串**不可变**，`format` 返回全新字符串，不修改原字符串；

3. 支持**位置参数、关键字参数、索引复用、格式控制、对象属性、下标取值**。

## 二、5 种传参方式

### 1\. 无索引占位符（按顺序匹配）

`{}` 不写数字，参数按传入顺序依次填充。

```python
s = "姓名：{}，年龄：{}".format("小明", 18)
print(s)  # 姓名：小明，年龄：18
```

### 2\. 数字索引占位符（重复复用参数）

`{0}` `{1}` 数字对应 `format` 内参数下标，**支持重复使用同一个参数**。

```python
# 同一个参数多次引用
s = "{0} + {1} = {0}".format(10, 5)
print(s)  # 10 + 5 = 10

# 打乱填充顺序
s2 = "{1}年，{0}岁".format(25, 2026)
print(s2)  # 2026年，25岁
```

### 3\. 关键字参数（key=value）

占位符写 `{key}`，`format(key=值)` 传参，适合参数多、顺序混乱场景。

```python
s = "姓名:{name}, 城市:{city}".format(name="小红", city="北京")
print(s)  # 姓名:小红, 城市:北京
```

### 4\. 容器传参：列表 / 元组下标取值

用 `{变量[下标]}` 直接读取列表、元组元素。

```python
lst = ["张三", 22]
s = "名字：{lst[0]}，年龄：{lst[1]}".format(lst=lst)
print(s)  # 名字：张三，年龄：22
```

### 5\. 字典传参：直接读取 key

两种写法：

1. `{字典[key]}`

2. `**字典` 解包，直接 `{key}`

```python
info = {"name": "小李", "score": 95}
# 方式1：指定字典名取key
s1 = "学生:{info[name]} 分数:{info[score]}".format(info=info)

# 方式2：**解包字典，最简写法
s2 = "学生:{name} 分数:{score}".format(**info)
print(s2)  # 学生:小李 分数:95
```

### 6\. 对象属性取值（类实例）

占位符 `{对象.属性}` 直接读取实例属性

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age

stu = Student("小刚", 19)
s = "姓名:{stu.name}，年龄:{stu.age}".format(stu=stu)
print(s)  # 姓名:小刚，年龄:19
```

## 三、核心：格式限定符 `{:格式}`

语法：

```Plain Text
{占位符索引/key : 填充符 对齐 宽度 ,千位分隔符 .精度 类型}
```

拆分结构：`{[name][!转换]:[格式说明]}`

### 1\. 基础格式符号总表

|符号|作用|
|---|---|
|`<`|左对齐（文本默认）|
|`>`|右对齐（数字默认）|
|`^`|居中对齐|
|`=`|数字符号与数字之间填充（仅数字）|
|`,`|千位分隔符|
|`.n`|浮点数保留 n 位小数；字符串截取 n 个字符|
|`d`|十进制整数|
|`f`|浮点数|
|`%`|百分比格式|
|`x/X`|十六进制小写 / 大写|
|`b`|二进制|
|`o`|八进制|

### 2\. 宽度、对齐、填充字符

格式：`{:填充字符+对齐+宽度}`
填充字符只能**单个字符**，不写默认空格填充。

```python
# 1. 居中对齐，总宽度10，*填充
print("{:*^10}".format("python"))  # **python**

# 2. 右对齐，宽度8，0填充（数字补零常用）
print("{:0>8}".format(123))  # 00000123

# 3. 左对齐，宽度6，-填充
print("{:-<6}".format("ab"))  # ab----
```

### 3\. 数字格式化（高频）

#### （1）整数进制转换

```python
num = 20
print("二进制 {:b}".format(num))   # 10100
print("八进制 {:o}".format(num))   # 24
print("十六进制小写 {:x}".format(num)) # 14
print("十六进制大写 {:X}".format(num)) # 14
print("十进制 {:d}".format(num))    # 20
```

#### （2）浮点数、小数精度

```python
f = 3.1415926
# 保留2位小数，四舍五入
print("{:.2f}".format(f))  # 3.14
# 保留4位小数
print("{:.4f}".format(f))  # 3.1416
# 固定总宽度10，保留3位小数，右对齐
print("{:10.3f}".format(f)) #      3.142
```

#### （3）千位分隔符

```python
num = 1234567
print("{:,}".format(num))  # 1,234,567
# 搭配小数
print("{:,.2f}".format(12345.678)) # 12,345.68
```

#### （4）百分比格式化

```python
rate = 0.785
print("{:.1%}".format(rate))  # 78.5%
print("{:.0%}".format(rate))  # 79%
```

#### （5）正负号控制

`+`：正数显示 \+，负数显示 \-；
`-`：仅负数显示负号（默认）；
空格：正数前空一格，负数负号。

```python
print("{:+d}".format(10))   # +10
print("{:+d}".format(-10))  # -10
print("{: d}".format(10))   #  10（前面空格）
print("{: d}".format(-10))  # -10
```

## 四、\!r / \!s / \!a 转换标记

在 `:` 前加 `!转换`，对参数先做类型转换再填充：

- `!s` 等价 `str()` 转为字符串（默认）

- `!r` 等价 `repr()` 打印原始格式

- `!a` 等价 `ascii()` 转 ASCII 字符

```python
text = "中文"
print("普通转换：{!s}".format(text))  # 中文
print("repr原始：{!r}".format(text))   # '中文'
print("ascii编码：{!a}".format(text))  # '\u4e2d\u6587'
```

## 五、嵌套 format（占位符嵌套）

宽度、精度可以用另一个 `{}` 动态传入，适合动态控制长度：

```python
# 外层{}的宽度、小数位数由内层参数控制
num = 3.1415
width = 10
prec = 2
s = "{:{w}.{p}f}".format(num, w=width, p=prec)
print(s)  #      3.14
```

## 六、特殊场景

### 1\. 输出大括号 `{}`

模板中要打印 `{` 或 `}`，需要**双写** `{{` / `}}` 转义：

```python
# 输出 {name} 原样文本
s = "模板示例：{{name}}，填充：{}".format("测试")
print(s)  # 模板示例：{name}，填充：测试
```

### 2\. 字符串截取

`.n` 作用在字符串时，表示只取前 n 个字符：

```python
s = "{:.3}".format("Python")
print(s)  # Pyt
```

## 七、format 与 f\-string、% 对比

1. **% 格式化**：旧式，类型限制严格，不支持复用、对象属性；

2. **str\.format\(\)**：兼容性极强（Python2/3 通用），功能全面，适合需要兼容低版本 Python 的项目；

3. **f\-string**：Python3\.6\+，写法最简、性能最优，新项目首选。

## 八、完整综合示例

```python
# 综合：字典传参、千位分隔、百分比、居中对齐
data = {"name": "销售A", "sales": 15689.23, "rate": 0.926}
template = """
员工：{name:^8}
销售额：{sales:,.2f}

"""
print(template.format(**data))
```

输出：

```Plain Text

```

## 九、常见踩坑点

1. 占位符数量少于 format 参数不会报错；占位符多于参数直接抛 `IndexError`；

2. 填充字符**只能单个字符**，写 `{:ab>5}` 直接报错；

3. `.n` 对字符串是截取，对浮点数是小数精度，逻辑不同；

4. 模板输出 `{}` 必须双大括号 `{{}}`，单括号会识别为占位符；

5. format 返回新字符串，必须变量接收，原字符串不会改变。
